# Домашнее задание к занятию "`Компоненты Kubernetes`" - `Шмагин Максим`

## 1. Описание задачи
Необходимо определить требуемые вычислительные ресурсы для кластера Kubernetes с учетом следующих вводных данных:
* Приложение включает фронтенд, бэкенд, базу данных и систему кеширования.
* База данных: 3 реплики, потребление 1 vCPU и 4 ГБ RAM на каждую.
* Система кеширования: 3 реплики, потребление 1 vCPU и 4 ГБ RAM на каждую.
* Фронтенд: 5 реплик, потребление 0.2 vCPU и 50 МБ RAM на каждую.
* Бэкенд: 10 реплик, потребление 1 vCPU и 600 МБ RAM на каждую.
* Требуется обеспечение отказоустойчивости (HA).

## 2. Расчет базовой нагрузки (Payload)
Суммарное потребление ресурсов компонентами приложения в штатном режиме работы:

| Компонент | Количество реплик | vCPU на единицу | RAM на единицу | Итого vCPU | Итого RAM |
| :--- | :--- | :--- | :--- | :--- | :--- |
| База данных | 3 | 1 | 4 GB | 3 | 12.0 GB |
| Система кеширования | 3 | 1 | 4 GB | 3 | 12.0 GB |
| Фронтенд | 5 | 0.2 | 50 MB | 1 | 0.25 GB |
| Бэкенд | 10 | 1 | 600 MB | 10 | 6.0 GB |
| **Всего** | **21** | | | **17 vCPU** | **~30.25 GB** |

## 3. Обеспечение отказоустойчивости и расчет узлов
Для выполнения требований отказоустойчивости реплики базы данных и кеша (по 3 экземпляра) должны быть распределены по разным узлам кластера (podAntiAffinity).
* **Минимальное количество Worker-узлов:** 3.
* **Резервирование (N+1):** Для сохранения работоспособности при выходе из строя одного узла требуется добавить еще один узел.
* **Итоговое количество Worker-узлов:** 4.

При отказе одного узла оставшиеся 3 узла должны полностью обслуживать базовую нагрузку (17 vCPU и 30.25 GB RAM). Требуемая полезная емкость одного узла (payload) составляет:
* **CPU:** 17 / 3 = 5.6 vCPU
* **RAM:** 30.25 / 3 = 10.08 GB

## 4. Учет служебных ресурсов (Overhead)
Для обеспечения работы операционной системы и системных компонентов Kubernetes (kubelet, kube-proxy, CNI, CSI и системные демоны) необходимо заложить резерв на каждый узел:
* Резерв CPU: ~1 vCPU
* Резерв RAM: ~2 GB

Итоговые требования к одному узлу (с учетом служебных ресурсов):
* **CPU:** 5.6 + 1.0 = 6.6 vCPU
* **RAM:** 10.08 + 2.0 = 12.08 GB

## 5. Итоговая спецификация кластера
Исходя из расчетов, оптимальным выбором инстанса у облачных провайдеров является конфигурация 8 vCPU / 16 GB RAM.

**Спецификация Worker-узлов:**
* **Количество узлов:** 4
* **Конфигурация одного узла:** 8 vCPU / 16 GB RAM
* **Суммарная емкость кластера:** 32 vCPU / 64 GB RAM

**Спецификация Control Plane (Master-узлы):**
* Для production-окружения также потребуется отказоустойчивый Control Plane.
* **Количество узлов:** 3 
* **Конфигурация одного узла:** 2 vCPU / 4 GB RAM
